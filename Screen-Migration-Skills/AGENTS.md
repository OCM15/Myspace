# Screen Migration AI Instructions

When working on a screen migration:

1. Read `skills/Screen-Migration-Orchestrator-Skill.md` first.
2. Read the other screen migration skills relevant to the task.
3. Create or update the applicable templates under `templates/`.
4. Do not implement before the legacy screen inventory is complete enough for the task.
5. Never infer missing requirements. Mark them `UNKNOWN`.
6. Treat `MISSING` and `UNKNOWN` as unresolved until explicitly resolved.
7. Preserve business behavior even when UI implementation changes.
8. After implementation, rerun traceability and interface checks.
9. Produce test evidence and a migration report.
